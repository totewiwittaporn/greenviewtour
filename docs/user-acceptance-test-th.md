## ทดสอบคืนอุปกรณ์

1. Stock → Loans & returns เลือกวันบริการ 20 กันยายนและเรือ DEMO
2. ดู BK-2026-000004 ซึ่งยังมีอุปกรณ์ค้างคืน
3. คืนบางส่วนแบบ Return ready ยอด Outstanding ต้องลดเท่าจำนวนคืนและเพิ่มของพร้อมใช้ที่จุดคืน
4. ไม่มีตัวเลือกส่งล้าง ของชำรุดหรือสูญหายยังเลือกแยกได้
5. จำนวนเกินยอดค้างต้องไม่บันทึกสำเร็จ

## อ่าน Network

- 200: คำขอสำเร็จ
- canceled ตามด้วยคำขอเดียวกัน 200: รอบโหลดเก่าถูกยกเลิก ตรวจผลหน้าจอรอบล่าสุด
- 409: อ่าน Response เพื่อแยกข้อขัดแย้งข้อมูลหรือเงื่อนไขธุรกิจ เช่น รออนุมัติราคา
- หากหน้าจอโหลดไม่สำเร็จหรือพบ 500/503 ให้เก็บชื่อคำขอ Status และ Response สำหรับตรวจต่อ อย่ากดบันทึกซ้ำรัว ๆ

## ขอบเขตที่พร้อมและที่ยังต้องกำหนด

ชุดนี้ครอบคลุม Booking/รถ/เรือ/ของยืม งานบริษัทที่มีอยู่ และราคาต่อรองราย Booking คู่มือหลักอยู่ที่ user-manual-th.md

ระบบบัญชีแยกประเภทเต็มรูปแบบ กฎภาษี/เงินเดือนอัตโนมัติ การเชื่อมธนาคาร และ LINE ออนไลน์ยังต้องกำหนดรายละเอียดและตั้งค่าก่อนเปิดใช้ ไม่ถือว่าเสร็จเพียงเพราะหน้าการเงินเดิมมีอยู่


## 6. สรุปภายใน Agent และเอกสารบริษัท

- เลือกเฉพาะ Booking DEMO ที่ COMPLETED + AGENT_CREDIT ของ Agent เดียวกัน ตรวจยอดรวมก่อนสร้างสรุป
- ตรวจว่า Booking ที่ออกสรุปแล้วไม่ปรากฏให้เลือกซ้ำ
- บันทึกรับชำระ DEMO บางส่วน ตรวจยอดค้าง แล้วรับส่วนที่เหลือ ตรวจสถานะ PAID
- ลองจำนวนเกินยอดค้าง: ต้องไม่มีรายการรับชำระเพิ่ม
- แนบภาพ/ไฟล์ DEMO ที่แถวรับชำระ พร้อมเลขเอกสารบริษัท ดาวน์โหลดแล้วต้องได้ไฟล์เดิม
- ปฏิเสธชนิด/ขนาดไฟล์ที่ไม่อนุญาต เก็บข้อมูลฟอร์มเมื่ออัปโหลดไม่สำเร็จ
- บัญชีไม่มีสิทธิ์ต้องไม่เห็น/ดาวน์โหลดเอกสารเงินเดือนแม้รู้ URL
- Admin Manager ส่งออก Payroll CSV ตามตัวกรอง ตรวจยอด ภาษาไทย และสถานะ
- ไม่ส่งเงินจริง ไม่ออกเอกสารภาษีจริง และไม่ส่ง LINE ในการทดสอบนี้
